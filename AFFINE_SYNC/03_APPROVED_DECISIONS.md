# Approved Decisions (Permanent)

These decisions are permanent policy for MPS Content Factory. Do not redesign or override any of these without explicit instruction.

## Product principles
- Workflow First, AI Second
- Official Mode is AI-free
- Original photos only
- Never modify people
- Never modify uniforms
- Never modify logos
- Never modify buildings
- Never modify vehicles
- Never modify dogs
- Photos, frames and text remain movable and editable

## Approved workflow
Dashboard → Choose Factory → Workspace → Upload Photos → Photo Queue → Choose Hero → Auto Layout → Edit Text → Export PNG

## Process rule
Do not redesign approved modules without explicit instruction.
